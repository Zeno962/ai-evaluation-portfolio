# LLM response evaluation

16 constructed comparisons stress arithmetic, extraction, uncertainty, grounding, policy fidelity, prompt injection, ambiguity and conflicting constraints. Preference positions are balanced by design; A and B do not identify models.

[Case study](CASE_STUDY.md) · [Rubric](rubric.md) · [Prompts and answers](cases.csv) · [Scorecards](scores.csv) · [Preferences](reference_evaluations.csv) · [Analysis](ANALYSIS.md) · [Portfolio](../../README.md)

Each response has instruction, correctness, completeness and clarity scores (0–2), a critical-error flag, an eight-point total and an acceptance decision. Preferences allow ties. The prompts provide a closed reference or elementary arithmetic/code behavior; no live factual assertions require external lookup.
